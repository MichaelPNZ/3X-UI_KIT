# Лицензия и сторонние компоненты

Код 3X-UI KIT распространяется по лицензии MIT, см. [LICENSE](LICENSE).
Она не распространяется на чужие компоненты ниже: у каждого своя лицензия.

3X-UI KIT – независимый проект, не связан с авторами перечисленных проектов.

## Сторонние компоненты, которые KIT скачивает и запускает при установке

KIT только скачивает и запускает их, исходный код этих проектов в репозитории не лежит.

| Компонент | Лицензия | Откуда |
|---|---|---|
| [3X-UI](https://github.com/MHSanaei/3x-ui) (панель; версия закреплена в скриптах) | GPL-3.0 | релиз на GitHub |
| [Xray-core](https://github.com/XTLS/Xray-core) (ядро; версия закреплена) | MPL-2.0 | релиз на GitHub |
| [mtg](https://github.com/9seconds/mtg) (MTProto) | MIT | входит в архив 3X-UI |
| [acme.sh](https://github.com/acmesh-official/acme.sh) (сертификаты) | GPL-3.0 | ставится установщиком 3X-UI |
| [nginx](https://github.com/nginx/nginx) | BSD-2-Clause | пакет дистрибутива (`apt`) |
| [jq](https://github.com/jqlang/jq) | MIT | пакет дистрибутива (`apt`) |
| [ufw](https://launchpad.net/ufw) | GPL-3.0 | пакет дистрибутива (`apt`) |

TUIC и AmneziaWG работают внутри панели 3X-UI, отдельным файлом KIT их не скачивает: их лицензии смотрите в репозитории панели.
Hysteria2 работает как подключение панели через ядро.

Лицензии сверены по файлам LICENSE самих проектов. Если у вас другая версия, ориентируйтесь на LICENSE в её репозитории.
