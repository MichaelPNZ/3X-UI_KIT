Для REALITY на сервере KIT 1.3.0 нужен клиент с X25519MLKEM768. Генератор ставит chrome и включает ML-KEM в Mihomo. Подтверждены по коду Xray 26.9.9 и Mihomo 1.19.32/1.19.33; поддержка более старых версий здесь не подтверждена. Совместимость клиентов. Для подписки используйте KIT 1.3.0: параметры из сторонней подписки определяет её поставщик.
